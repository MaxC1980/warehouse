# 权限管理（RBAC）

基于角色的访问控制，替代旧的 3 级数值权限。

## 数据模型

- 4 张表：`role`、`user_role`、`permission`、`role_permission`
- 31 条权限：14 模块 × 3 动作（view/edit/approve），部分模块只有 view 或 manage（含 product 模块）
- 默认角色：管理员（全部）、操作员（view+edit）、查看员（仅 view）

## 三层防护

### 路由层

`@require_permission('module', 'action')` 装饰器，从 `session.permissions` 查 set，不走 DB。

装饰器自动识别 API/HTML：
- API 请求（`/api/*` 路径或 `Content-Type: application/json`）→ 返 JSON 401/403
- 页面请求 → 302 跳 /login

### 页面层

- `@login_required` 装饰器：未登录跳 /login
- `utils/page_permissions.py` endpoint 映射：精确匹配 `request.endpoint` → 权限要求

### 模板层

`has_perm(module, 'action')` 控制菜单和按钮显隐。

```html
{% if has_perm('material', 'edit') %}<button>新增</button>{% endif %}
```

## 管理页面

- `/admin/roles-page`（角色管理）
- `/admin/users-page`（用户管理）

## 新增模块需改的位置

1. `database.py` — 加种子数据 (permission 表 + 默认 role_permission)
2. 路由装饰器 — `@require_permission('module', 'action')`
3. `templates/base.html` — 加菜单
4. `utils/page_permissions.py` — 加 endpoint 映射
5. 模板按钮 — 用 `{% if has_perm(...)}` 包裹
