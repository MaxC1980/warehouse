# 新增功能模块清单

RBAC 权限系统下，新增功能模块需改 6 个地方。

## 1. database.py — 权限种子数据

```python
# 在 permissions 列表中添加
('new_module', 'view', '菜单组-新模块'),
('new_module', 'edit', '菜单组-新模块'),
# 如需审核
('new_module', 'approve', '菜单组-新模块'),
```

启动时自动同步到 permission 表（INSERT OR IGNORE + UPDATE）。

## 2. create_app.py — 页面路由 + 路径映射

```python
# 页面路由
@app.route('/new-module')
@login_required
def new_module():
    return render_template('new_module.html')

# PAGE_PERMISSIONS 列表中添加
('/new-module', 'new_module', 'view'),
('/new-module/new', 'new_module', 'edit'),  # 如有新增页
```

## 3. templates/base.html — 菜单项

```html
{% if has_perm('new_module', 'view') %}
<a href="/new-module">新模块</a>
{% endif %}
```

下拉菜单同理，整个下拉用多个 `has_perm` 的 or 判断是否显示。

## 4. routes/xxx.py — API 路由装饰器

```python
from utils.decorators import require_permission

@bp.route('/new-module', methods=['POST'])
@require_permission('new_module', 'edit')
def create():
    ...

@bp.route('/new-module/<int:id>/approve', methods=['POST'])
@require_permission('new_module', 'approve')
def approve(id):
    ...
```

## 5. 模板按钮 — Jinja2 条件渲染

```html
{% if has_perm('new_module', 'edit') %}
<button>新增</button>
{% endif %}
```

不要用 JS 隐藏按钮（会闪烁），用 Jinja2 服务端控制。

## 6. docs/ — 文档同步

- `docs/数据字典.md` — 新表定义
- `docs/业务逻辑.md` — 业务规则
- `CLAUDE.md` — 架构/路由清单（如有新文件）

## 不需要改的

- 权限管理页面自动显示新权限（从 permission 表读取）
- 角色分配时新权限自动出现在权限矩阵中
- `before_request` 路径映射只需加一行
