# 数据字典

## user（用户）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| username | TEXT | 用户名（唯一） |
| password | TEXT | 密码（werkzeug hash 存储，旧明文登录时自动升级） |
| created_at | DATETIME | 创建时间 |

## role（角色）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| name | TEXT | 角色名称（唯一） |
| description | TEXT | 描述 |
| is_system | INTEGER | 系统内置：1=是（不可删除）、0=否 |
| created_at | DATETIME | 创建时间 |

## user_role（用户-角色关联）

| 字段 | 类型 | 说明 |
|------|------|------|
| user_id | INTEGER | 用户 ID → user.id |
| role_id | INTEGER | 角色 ID → role.id |

主键：`(user_id, role_id)`

## permission（权限定义）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| module | TEXT | 模块名（如 material、in_order） |
| action | TEXT | 动作：view、edit、approve、manage |
| name | TEXT | 显示名（如 物料管理-查看） |

唯一约束：`(module, action)`

## role_permission（角色-权限关联）

| 字段 | 类型 | 说明 |
|------|------|------|
| role_id | INTEGER | 角色 ID → role.id |
| permission_id | INTEGER | 权限 ID → permission.id |

主键：`(role_id, permission_id)`

## employee（员工/经手人）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| name | TEXT | 姓名（唯一） |
| department | TEXT | 部门 |
| phone | TEXT | 电话 |
| remark | TEXT | 备注 |
| created_at | DATETIME | 创建时间 |

## material_category（物料分类）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| code | TEXT | 分类编码（唯一），2位大类 + 2位小类 |
| name | TEXT | 分类名称 |
| parent_code | TEXT | 父级分类编码，大类为 NULL |
| level | INTEGER | 层级：1=大类、2=小类 |

## material（物料）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| code | TEXT | 物料编码（唯一） |
| name | TEXT | 物料名称 |
| spec | TEXT | 规格型号 |
| unit | TEXT | 单位 |
| category_code | TEXT | 分类编码 |
| manufacturer | TEXT | 品牌/供应商 |
| storage_condition | TEXT | 存储条件，默认"常温" |
| shelf_life | INTEGER | 保质期（天） |
| remark | TEXT | 备注 |
| is_reusable | INTEGER | 是否可回用：0=否、1=是 |
| safety_stock | DECIMAL(16,2) | 安全库存量 |
| created_at | DATETIME | 创建时间 |

## supplier（供应商）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| name | TEXT | 供应商名称 |
| contact | TEXT | 联系人 |
| phone | TEXT | 联系电话 |
| address | TEXT | 地址 |
| created_at | DATETIME | 创建时间 |

## in_order（入库单主表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| order_no | TEXT | 入库单号（唯一） |
| supplier_id | INTEGER | 供应商 ID → supplier.id |
| operator_id | INTEGER | 操作员 ID → user.id |
| status | TEXT | 状态：pending=待审核、approved=已审核、cancelled=已取消 |
| remark | TEXT | 备注 |
| receiver | TEXT | 经手人 |
| purpose | TEXT | 用途 |
| receiver_date | DATE | 入库日期 |
| created_at | DATETIME | 创建时间 |
| approved_at | DATETIME | 审核时间 |
| approved_by | INTEGER | 审核人 ID → user.id |

## in_order_item（入库单明细）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| order_id | INTEGER | 入库单 ID → in_order.id |
| material_id | INTEGER | 物料 ID → material.id |
| batch_no | TEXT | 批次号 |
| production_date | DATE | 生产日期 |
| expiry_date | DATE | 有效日期 |
| quantity | DECIMAL(16,2) | 数量 |
| unit_price | DECIMAL(16,2) | 单价 |
| remark | TEXT | 备注 |

唯一约束：`(order_id, material_id, batch_no)` — 同一入库单内相同物料+批次的明细不能重复。

## out_order（出库单主表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| order_no | TEXT | 出库单号（唯一） |
| operator_id | INTEGER | 操作员 ID → user.id |
| status | TEXT | 状态：pending=待审核、approved=已审核、completed=已完成 |
| remark | TEXT | 备注 |
| purpose | TEXT | 用途 |
| created_at | DATETIME | 创建时间 |
| approved_at | DATETIME | 审核时间 |
| approved_by | INTEGER | 审核人 ID → user.id |
| department | TEXT | 部门 |
| receiver | TEXT | 领用人 |
| receiver_date | DATE | 出库日期 |

## out_order_item（出库单明细）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| order_id | INTEGER | 出库单 ID → out_order.id |
| material_id | INTEGER | 物料 ID → material.id |
| batch_no | TEXT | 批次号 |
| unit_price | DECIMAL(16,2) | 单价 |
| remark | TEXT | 备注 |
| requested_quantity | DECIMAL(16,2) | 申请用量 |
| actual_quantity | DECIMAL(16,2) | 实际用量 |
| initial_gross_weight | DECIMAL(16,2) | 领用毛重（kg，仅可回用物料） |
| shipment_info | TEXT | 实发信息（仅可回用物料） |

## inventory（库存）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| material_id | INTEGER | 物料 ID → material.id |
| batch_no | TEXT | 批次号 |
| production_date | DATE | 生产日期 |
| expiry_date | DATE | 有效日期 |
| quantity | DECIMAL(16,2) | 当前库存数量 |
| in_order_item_id | INTEGER | 来源入库明细 ID → in_order_item.id |
| updated_at | DATETIME | 更新时间 |

唯一约束：`(material_id, batch_no)` — 所有库存记录中，相同物料+批次号的记录不能重复（库存表唯一）。

## 索引

| 表 | 索引列 | 类型 | 目的 |
|----|--------|------|------|
| in_order | order_no | 普通 | 入库单号快速查找 |
| out_order | order_no | 普通 | 出库单号快速查找 |
| inventory | material_id | 普通 | 库存按物料查询 |
| return_order | order_no | 普通 | 退库单号快速查找 |
| return_order | related_out_order_id | 普通 | 按关联出库单查找退库 |
| in_order_item | order_id | 普通 | 查单/查明细 |
| out_order_item | order_id | 普通 | 查单/查明细 |
| return_order_item | return_order_id | 普通 | 查单/查明细 |
| in_order_item | order_id, material_id, batch_no | **唯一** | 同一入库单内相同物料+批次不能重复 |
| in_order_item | material_id | 普通 | pending_in enrich |
| out_order_item | material_id, batch_no | 普通 | pending_out enrich |
| return_order_item | out_order_item_id | 普通 | 退库审核 + reusable JOIN |
| in_order | status | 普通 | 状态过滤 |
| out_order | status | 普通 | 状态过滤 |
| return_order | status | 普通 | 状态过滤 |
| in_order | created_at | 普通 | 默认排序 |
| out_order | created_at | 普通 | 默认排序 |
| inventory | expiry_date | 普通 | 过期过滤 |
| reusable_material_weight | out_order_item_id | 普通 | 退库审核 |
| user_role | user_id | 普通 | 登录/权限查询 |
| user_role | role_id | 普通 | 角色分配 |
| role_permission | role_id | 普通 | 角色管理 |
| bom | product_id | 普通 | 按产品查 BOM |
| bom_substitute | bom_id | 普通 | 按 BOM 行查替代物料 |

## product（产品/成品）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| code | TEXT | 产品编码（唯一），自动生成：取最大数值+1 按8位填充 |
| name | TEXT | 产品名称 |
| spec | TEXT | 规格型号 |
| unit | TEXT | 单位，默认"个" |
| disabled | INTEGER | 禁用标记：0=启用、1=禁用（默认0） |
| remark | TEXT | 备注 |
| created_at | DATETIME | 创建时间 |

## bom（产品物料清单，单层）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| product_id | INTEGER | 产品 ID → product.id |
| material_id | INTEGER | 物料 ID → material.id |
| qty_per_unit | DECIMAL(16,4) | 单件产品所需物料数量（4 位小数） |
| remark | TEXT | 备注 |

唯一约束：`(product_id, material_id)` — 同一产品内相同物料不能重复。

## bom_substitute（BOM 替代物料）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER | 主键 |
| bom_id | INTEGER | BOM 行 ID → bom.id |
| material_id | INTEGER | 替代物料 ID → material.id |
| priority | INTEGER | 优先级（1=首选），仅展示用 |
| remark | TEXT | 备注 |

唯一约束：`(bom_id, material_id)` — 同一 BOM 行内相同替代物料不能重复。

用途：主物料库存不足时，替代物料库存合并计入可用量，用于缺料检查与最大可生产数计算。
